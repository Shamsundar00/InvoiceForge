What Is InvoiceForge?
An AI-powered bulk invoice generation tool built with Next.js 16 + TypeScript + TailwindCSS v4. Users upload an Excel file containing client data (names, amounts, dates, etc.), select/customize invoice templates, optionally generate AI descriptions, and bulk-generate professional PDF invoices with QR codes, sequential numbering, and audit trails.

Tech Stack
Frontend: Next.js 16 (App Router), React 19, Framer Motion, Lucide Icons, Recharts
Backend: InsForge.dev (BaaS — replaces Prisma/SQLite)
AI: Google Gemini via @ai-sdk/google for AI invoice descriptions
PDF: Server-side HTML-to-PDF generation
Excel: xlsx library for parsing, exceljs for generating sample templates
Current Architecture — Dual-Mode Provider Pattern
The app has an abstraction layer at /src/lib/providers/ that allows switching between a local Prisma backend and the InsForge cloud backend via a single env var DEPLOYMENT_MODE.

File Structure:

src/lib/providers/
├── types.ts              # Generic interfaces (DatabaseProvider, StorageProvider, AuthProvider)
├── index.ts              # Factory — exports db, storage, auth based on DEPLOYMENT_MODE
├── local/
│   ├── database.ts       # Prisma/SQLite implementation (WORKING)
│   ├── storage.ts        # Local filesystem storage (WORKING)
│   └── auth.ts           # Local auth stub
└── insforge/
    ├── database.ts       # InsForge SDK implementation (STUB — NEEDS REAL CODE)

Provider Interfaces (types.ts):

typescript
export interface DatabaseProvider {
  getSetting(key: string): Promise<any>;
  updateSetting(key: string, value: any, category?: string): Promise<any>;
  getAllSettings(category?: string): Promise<any[]>;
  createAuditLog(data: any): Promise<any>;
  deactivateAllSources(): Promise<void>;
  createSource(data: any): Promise<any>;
  getActiveSource(): Promise<any>;
  updateSource(id: string, data: any): Promise<any>;
  deleteSource(id: string): Promise<void>;
  getDashboardData(): Promise<any>;
}
export interface StorageProvider {
  uploadFile(filename: string, fileData: Buffer): Promise<string>;
  downloadFile(filePath: string): Promise<Buffer>;
  deleteFile(filePath: string): Promise<void>;
}
export interface AuthProvider {
  getSession(): Promise<any>;
}

InsForge SDK Reference (Already Researched)
Install:

bash
npm install @insforge/sdk
Initialize (Server-side for Next.js):

typescript
import { createClient } from '@insforge/sdk';
const insforge = createClient({
  baseUrl: process.env.INSFORGE_URL || 'http://localhost:7130',
  isServerMode: true,
});
Database CRUD (PostgREST-style):

typescript
// SELECT
const { data, error } = await insforge.database.from('sources').select('*').eq('is_active', true);
// INSERT
const { data, error } = await insforge.database.from('sources').insert([{ fileName: 'test.xlsx', rowCount: 100 }]);
// UPDATE
const { data, error } = await insforge.database.from('sources').update({ is_active: false }).eq('id', sourceId);
// DELETE
const { data, error } = await insforge.database.from('sources').delete().eq('id', sourceId);
